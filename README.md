# OverStruct

A small datapack that easily tweaks spawn rates of structures in Minecraft. To be used before world generation.

## To Install and Use

1. Download the repo.

2. *Optional:* Run `ChangeSettings.py` to adjust separation and spacing to your own values. This datapack defaults to `spacing=2` and `separation=1`

3. Create a new world in Minecraft. In the Datapacks section, add this repo's folder to it.

4. Finish creating the world. It may take an extended amount of time and CPU resources, as the world may need to spawn a large amount of structures.
